# Морозилка с заботой

Небольшое React-приложение о домашней еде, заготовках и спокойном планировании недели.

## Запуск

```bash
npm install
npm run dev
```

## Что есть сейчас

- главная страница и адаптивный интерфейс;
- каталог из шести рецептов с поиском и категориями;
- избранное, которое сохраняется в браузере;
- страницы «Морозилка» и «Меню на неделю»;
- маршруты через `HashRouter`, совместимые с GitHub Pages.

## Публикация

```bash
npm run deploy
```

Перед первым деплоем создайте GitHub-репозиторий и настройте в нём GitHub Pages на ветку `gh-pages`.
